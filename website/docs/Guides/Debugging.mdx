# Debugging

Mokkery provides tools to simplify debugging in your tests.

## Mock state

You can print the state of a mock using `printMokkeryDebug`:

```kotlin
val mock = mock<Foo>()
// ...
printMokkeryDebug(mock)
```
This produces a JSON-like structure printed with `println`:

```
mock {
	id = your.package.Foo(1)
	mode = strict
	answers {
		getAt(index = any()) returns -1
		getAt(index = 1) returns 2
		getAt(index = 2) returns 4
		getAt(index = 3) returns 6
	}
	calls {
		getAt(index = 0)
		getAt(index = 1)
		getAt(index = 2)
	}
}
```

You can also create this debug string manually using `mokkeryDebugString` and process it as needed.

## Logging calls

To log each call to a mock, use `MokkeryCallLogger`:

```kotlin
private val logger = MokkeryCallLogger()

@BeforeTest
fun before() {
    MokkeryScope.global.callHooks.beforeAnswering.register(logger)
}

@AfterTest
fun after() {
    MokkeryScope.global.callHooks.beforeAnswering.unregister(logger)
}
```
This approach ensures the logger is added only for the duration of a single test class.

For quick debugging, you can simply use:

```kotlin
MokkeryScope.global.callHooks.beforeAnswering.register(MokkeryCallLogger())
```

It's possible to register logger just for specific mock:

```kotlin
MokkeryScope.from(mock).callHooks.beforeAnswering.register(MokkeryCallLogger())

// or on init

mock<Foo> {
    callHooks.beforeAnswering.register(MokkeryCallLogger())
}
```

It is possible to register logger for [mock and spy factories](../Guides/Factories).
The logger is then applied to every instance created by a given factory:

```kotlin
val factory = mockFactoryOf(Foo::class, Bar::class) {
    callHooks.beforeAnswering.register(MokkeryCallLogger())
}
```
